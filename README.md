**深本思维 · 从理解一题，走向理解一类问题**

我关注数学学习中的三个环节：**弄通情景 → 知识联想 → 顺逆推理**。

从学生的实际作答寻找读题、概念、推理和表达中的卡点，再通过解释依据、独立作答和变式练习，检验理解能否迁移。

这一方向参考邹华权《深本思维·数学的本质》书稿，分享方法整理与学习实践；相关 Skill 尚未公开。

**AI 实践 · 让每次尝试留下可复用的方法**

记录 Skill 的整理、验证和使用过程。让一个想法变成可以调用的工具，再用真实问题检查它是否有用。

### 我相信的几件事

**先弄清问题，再寻找方法。** 好的框架从具体事实开始，也要接受事实的修正。

**理解要能解释，方法要能迁移。** 说清为什么成立，再放进新的情景检验。

**判断需要多个角度。** 用不同人物分析同一问题，也检查他们各自的盲点。

**依据和局限一起保留。** 原文、历史事实、框架归纳和现实建议分别注明。历史人物的成功与代价都值得研究。
